# 简行 EasyUp

一款把**习惯、健康、记账、成长规划**都装进口袋的本地记录工具。界面简洁、开箱即用，**所有数据只保存在自己手机里，不上传任何服务器**。

> 在线使用：<https://posama-cloud.github.io/Easyup/>
> 安装指引（含二维码）：<https://posama-cloud.github.io/Easyup/install.html>

---

## 它能做什么

简行把日常要「记下来的事」分成四大模块，按需启用，不用缴费、不用注册。

### 习惯培养
每天想坚持的「小事」都在这里：喝水、阅读、运动……

- 支持三种完成方式：**完成 / 未完成**、**按数量**（次、个、组、页、公里……）、**按时长**（分钟、小时）
- 可设置频率（每天 / 工作日 / 每周几天）和每周休息上限，允许计划性休息
- 首页实时显示「今天的 N 件事」，勾选即完成，重复打卡可回退

### 健康记录
体重、饮食、运动三件套，慢慢长出一条可回看的时间线。

- **体重**：记录体重，自动算基础代谢（BMR）与每日消耗（TDEE）
- **饮食**：记每餐热量（kcal），可从食物库选择或自定义录入
- **运动**：记运动项目、时长与预计消耗
- 首页本周总结自动汇总「吃进去多少、动出去多少、热量差多少」

### 个人记账
每一笔钱花向哪里，心里有数。

- 记**支出 / 收入**，支持日期的历史补记
- **预算项**：给每份钱起个名字（如固定支出、日常支出）并设限额，支出自动从对应预算里扣，随时看剩余
- 月度预算总额与起始日设置，首页显示预算剩余与本周支出

### 成长规划
把大目标拆成小动作，用 PDCA 循环推进。

- **P（Plan）** 设定目标与截止时间
- **D（Do）** 设置具体动作，可分「打卡制」与「确认制」，支持撤销
- **C（Check）** 按时检查计划，留痕
- **A（Act）** 调整项，复盘后修正方向
- 目标进度、里程碑与打卡记录全部留痕可回看

### 综合分析
首页与「分析」页自动生成各模块的趋势：体重变化、习惯完成率、收支与预算、成长里程碑，只展示你已启用模块的数据。

### AI 智能分析（可选）
接入你自己的大模型 API Key（支持 **DeepSeek、千问、OpenAI**），开启三个能力：

- **趋势分析**：从你的记录里读趋势
- **行动建议**：给出下一步可以做什么
- **智能问答**：直接问它关于你数据的问题

> 密钥仅保存在本机；调用时由你的浏览器直连所选 AI 服务商，简行本身不接触、不存储你的记录，也没有中间服务器。

### 其他贴心设计
- **外观主题**：多套配色一键切换
- **简约模式**：隐藏多余文案，安静记录
- **历史日历**：右上角日历可回看任意一天的历史留痕（支出、体重、饮食、运动、习惯完成等）
- **数据备份 / 迁移**：一键导出备份文件，换手机、换浏览器时导入即可无缝搬家

## 怎么用（安装教程）

简行是**网页应用**，不需要去应用商店下载。

**图文安装教程（含二维码，照着点就行）**：<https://posama-cloud.github.io/Easyup/install.html>
**网站地址**：<https://posama-cloud.github.io/Easyup/>

### 安卓手机（两种方式任选）

**方式一 · 网页端添加到桌面（推荐，免费）**
用 Chrome 打开网站地址 → 点右上角「⋮」→「添加到主屏幕 / 安装应用」→ 桌面出现简行图标，点开全屏使用。网址不变，以后打开自动是最新版。

**方式二 · 安装 APK（可离线使用）**
下载最新 APK 文件直接安装。签名长期不变，后续版本可直接覆盖升级、数据不丢。

### iPhone / iPad（仅支持添加到主屏幕）

用 **Safari** 打开网站地址 → 点底部「**分享**」→ 下滑点「**添加到主屏幕**」→ 保持名称「简行」→ 点「添加」，桌面出现简行图标，点开即全屏使用。

> 苹果系统不允许像安卓那样直接安装网页应用的安装包（系统限制），所以苹果端只有「添加到主屏幕」这一种方式。

### 关于数据
- 所有数据保存在**当前设备本地**（浏览器本地存储），不联网、不上传
- 换手机 / 换浏览器时不会自动跟随，请在旧设备「设置 → 数据备份 → 导出备份」，再到新设备「导入备份」
- 卸载应用或清除浏览器网站数据会清空记录，重要数据请先导出备份

## 各模块使用教程

### 首次使用
1. 打开后按引导启用需要的模块（习惯 / 健康 / 记账 / 成长），随时可增删
2. 在模块内完成首次设置（如健康档案、预算项、第一个习惯），首页即出现对应卡片

### 常用操作速查
| 我想…… | 怎么做 |
| --- | --- |
| 快速记一笔 | 首页右下角「＋ 快速记录」悬浮按钮 |
| 记支出并选预算 | 快速记录 → 记支出 → 输入金额后自动弹出预算项选择（或点「从哪个预算项扣除」） |
| 改习惯目标 | 首页习惯卡片 → 进入设置：完成方式、数量/时长、频率、每周休息 |
| 设预算项 | 记账模块 → 「添加预算项」：名称 + 限额 |
| 看趋势 | 底部「分析」→ 各模块卡片；接入 AI 后可点「开始分析」看深度解读 |
| 配 AI | 点页面左上方「简」logo → 选服务商 → 粘贴密钥 → 保存并开启 |
| 备份迁移 | 设置 → 数据备份 → 导出 / 导入 |

## 隐私说明

- 不上传、不联网收集任何行为数据；简行没有服务器，记录只属于你自己
- AI 功能为可选；密钥本地保存，调用直连官方服务商，介意者可不开启，其余功能完整可用

## 技术实现

- **前端**：React + Vite 单页应用，移动端优先响应式布局
- **移动端**：Capacitor 打包安卓 APK（同一套代码）
- **部署**：GitHub Pages 静态托管，附带 PWA 清单与图标，支持「添加到主屏幕」全屏运行
- **存储**：浏览器 localStorage（键统一为 `easyup-` 前缀，便于备份迁移）
- **目录**：`mobile/` 为移动端入口，`app/` 为应用源码，`public/` 为静态资源，`android/` 为原生工程

### 本地开发 / 构建
```bash
npm install
npm run build:mobile        # 构建移动端网页产物（dist-mobile）
npm run android:apk         # 构建安卓调试版 APK
npm test                    # 运行测试
```
